# Dataset Diversity & De-duplication Report

This report provides an empirical analysis of query diversity, lexical overlap, and cross-split leakage 
across the CarePilot evaluation corpora (`gold_scripted_candidate`, `silver`, and `rq3_stream`).

## Normalization Regular Expressions

- **Greeting Regex**:
  ```regex
  ^(?:hello|hi doctor|hi|dear doctor|good morning|good afternoon|good evening|doctor|hey|please help me understand:?|could you explain:?|i would like to ask:?)\b[\s,:-]*
  ```
- **Sign-off Regex**:
  ```regex
  [\s,.:!]+(?:thanks|thank you|please advise|please let me know|looking forward to hearing from you|sincerely|best regards|thank you for your guidance|thanks in advance)[\s,.:!]*$
  ```

## Key Audit Findings

1. **Gold Scripted Candidate Severe Duplication & Leakage**: Although `gold_scripted_candidate.jsonl` contains 500 rows, there are only **~40 distinct base scenarios** (38 clusters@0.7, 32 clusters@0.5) across the entire corpus. Most variations were generated by simply appending greetings ('Hi doctor,', 'Hello,') or sign-offs ('Thanks.', 'Please let me know.').
2. **Cross-Split Leakage in Gold**: At token-Jaccard >= 0.7, **27 clusters span both dev and test**. This confirms substantial data leakage between dev and test in `gold_scripted_candidate.jsonl`, rendering it **unsuitable as an unadjudicated benchmark** without de-duplication and strict scenario partitioning.
3. **Silver Partitioning Integrity**: In contrast, the silver evaluation split (`silver-dev+test`, 2,080 rows) demonstrates **zero cross-split leakage at Jaccard >= 0.7** (0 spanning clusters) because scenario families are strictly partitioned into disjoint sets (8 dev families vs. 8 test families with 130 queries each).
